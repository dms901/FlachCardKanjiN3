# Master Kanji N3

Aplikasi Flashcard interaktif untuk belajar Kanji JLPT N3. Dibuat dengan Next.js 14, TailwindCSS, dan Supabase Auth.

[Live Demo](https://flach-card-kanji-n3-3sbwcrjgu-dms901s-projects.vercel.app)

## ✨ Fitur

- **Auth Supabase** - Login & Register dengan email
- **Flashcard Flip** - Ketuk kartu untuk lihat arti, kunyomi, onyomi
- **Progress Tracking** - Progress bar per bagian + tandai "Sudah Hafal"
- **Pembagian Part** - Kanji dibagi per bagian biar gak overwhelming
- **Fitur Acak** - Tombol acak kartu biar gak hafal urutan
- **Responsive** - Bisa dipakai di HP & Desktop
- **UI Clean** - TailwindCSS, simple dan fokus belajar

## 🛠️ Tech Stack

- **Framework**: Next.js 14 App Router
- **Styling**: TailwindCSS
- **Database & Auth**: Supabase
- **Language**: TypeScript + React
- **Deploy**: Vercel
